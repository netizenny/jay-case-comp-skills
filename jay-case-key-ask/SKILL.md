# Case Comp: Key Ask

Step 1 of 3 (Key Ask, then Issues, then Solutions). Do only this step.

## Input
The case summary pasted in the chat. If there is none, ask Jayden to paste it. Do not ask for the full case packet.

## Rules
- Only use the case summary. If something has to be made up, label it ASSUMPTION.
- Stay in your lane: no issues, no background, no solutions, no financials.
- Short. Bullet points. Under 1 page.
- Simple words.

## Output
1. **Key ask**: what the case is really asking the team to answer, in 1 to 2 sentences.
2. **Constraints in the case**: 2 to 4 bullets (who it is for, deadline, budget, scope), only if the summary states them.

## Finish
End with one line: Jayden can edit this now, then move to the Issues step. Do not continue to issues on your own.
