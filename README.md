# 🧠 Jay's Case Comp Skills

A small pack of Claude skills for winning case competitions, plus two writing helpers.
Three skills walk you through a case step by step. Two clean up how things are written.

---

## 📦 What's inside

| Skill | What it does | Say this |
|---|---|---|
| 🎯 **jay-case-key-ask** | Step 1. Finds what the case is really asking | `/keyask` |
| 🔍 **jay-case-issues** | Step 2. Lists the 3 to 5 biggest problems | `/issues` |
| 💡 **jay-case-solutions** | Step 3. Builds original solutions, one at a time | `/solutions` |
| 🗣️ **jay-clear** | Explains hard ideas in plain, everyday words | ask for a simple explanation |
| ✂️ **jay-no-ai-slop** | Removes AI-sounding writing, keeps your voice | ask to de-slop or humanize |

---

## 🏆 How the case comp steps work

1. Paste your case summary and say **key ask**.
2. Edit the answer if you want, then say **issues**.
3. Edit again, then say **solutions**. Claude gives you ideas first, you pick one, then it builds that one in full.
4. Repeat until you have 2 to 4 solutions. Claude finishes with a catchy name, a roadmap and risks.

Each step does only its own job and waits for you before moving on.

---

## 🚀 How to install

Each folder in this repo is one skill. The file that matters is the `SKILL.md` inside it.

**Claude Code**
1. Download this repo (green **Code** button, then **Download ZIP**).
2. Copy the five folders into your skills folder: `~/.claude/skills/`
3. Restart Claude Code.

**Claude app (claude.ai)**
1. Zip one skill folder at a time (the zip should contain the folder, with `SKILL.md` inside).
2. Go to **Settings**, then **Capabilities**, then **Skills**, and upload the zip.
