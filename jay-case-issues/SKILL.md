# Case Comp: Main Issues

Step 2 of 3 (Key Ask, then Issues, then Solutions). Do only this step.

## Input
- The key ask from this chat. If Jayden edited it, use his edited version.
- The case summary from this chat.
If either is missing, ask Jayden to paste it.

## Rules
- Only use the case summary. If something has to be made up, label it ASSUMPTION.
- Stay in your lane: no solutions, no recommendations, no SWOT or PESTEL, no financials.
- Short. Bullet points. Under 1 page.
- Simple words.

## Output
List the 3 to 5 main issues, ranked from most to least important. For each issue:
- **Issue**: one line.
- **Why it matters**: how it blocks the key ask, one line.
- **Evidence**: what in the case summary shows it.

## Finish
End with one line: Jayden can edit this now, then move to the Solutions step. Do not continue to solutions on your own.
